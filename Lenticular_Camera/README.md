# 视差实验室 / Lenticular Camera

独立、零依赖的手机摄像头交互项目，浏览器内处理，不上传图像。不会修改其他项目。

## 手机独立使用（正式使用方式）

手机直接打开网页，由手机自己的摄像头采集图片，图像处理、移动跟踪和结果显示都在同一部手机的浏览器中完成。使用时不需要电脑开机、不需要连接电脑，也不需要安装 Node.js 或应用。

首次发布时，将以下四个文件放在同一个 HTTPS 静态网站目录中：

- `index.html`
- `style.css`
- `core.js`
- `app.js`

发布后在手机浏览器打开网站地址，点击「打开后置摄像头」并允许相机权限，然后按下面的步骤取样、设置 LPI 并移动手机。网站仅提供页面文件，不接收摄像头画面，也不需要图像处理后端。

手机摄像头和方向传感器需要 **HTTPS**。请使用发布后的网站地址，而不是手机上的 `localhost`、电脑局域网 HTTP 地址或直接打开下载的 HTML 文件。当前仓库包含网页源码，尚未发布为可供手机直接访问的网站链接。

## 电脑本地开发预览（可选）

以下命令仅供修改代码时调试，不是手机正式使用的前提。

```powershell
cd D:\IMA-Creative-Computing\Lenticular_Camera
node serve.cjs
```

电脑打开 http://localhost:3010。内置六帧交错示例可直接拖动观看角度。

手机摄像头和方向传感器需要 **HTTPS**。直接使用 `http://电脑局域网IP:3010` 只能体验滑块，通常不能打开相机。可将此目录的 index.html、style.css、core.js、app.js 放到 HTTPS 静态托管，或用可信 HTTPS 隧道连接 3010 端口。也可给本地服务器配置手机信任的 TLS 证书：

```powershell
$env:TLS_CERT = 'C:\path\trusted-cert.pem'
$env:TLS_KEY = 'C:\path\trusted-key.pem'
node serve.cjs
```

只有选择这种局域网开发调试方式时，手机与电脑才需可互相访问；证书必须匹配访问的域名/IP，系统防火墙需允许所选端口。正式使用 HTTPS 静态网站时，没有这项要求。

## 使用

1. 打开后置摄像头，让图片与取样框对齐、保持平行，调整框大小。点击「取样图片并归零」。取样会固定当前图片，随后相机仅负责运动跟踪。
2. 输入制作时使用的 LPI、交错帧数、条纹方向，以及取样框内对应的实际尺寸（横条纹填高度，竖条纹填宽度）。相机取样没有自动透视矫正，裁切起点通过偏移滑块校准。
3. 上下平移手机，小幅度保持与图片平行。视觉跟踪将图片相对校准帧的位移映射为 −30° 至 +30° 的模拟角度。竖条纹使用左右移动。超出范围或跟踪不稳时重新归零。
4. 更清晰的方式：导入原始交错文件，设置它的完整实际跨度；打开相机对准实体图，点击「以当前位置归零」。此时不点击取样，以免覆盖原图。
5. 可选启用倾斜控制，授权后第一笔方向数据为中点；点击同一按钮可关闭。该模式测量转动而非平移。手动拖动会暂停运动控制，再次归零可恢复视觉跟踪。

## 原理与限制

光栅节距（源图像素）= 图片像素跨度 × 25.4 / (LPI × 实际跨度 mm)。每个周期分成 N 个等宽帧条纹，按模拟角度选择对应条纹中心并重建视图。支持等宽、等周期交错，不适用于未知厂商的特殊交错编码。LPI 不会自动识别，不能单靠 LPI 推断帧数与光学视角。固定 ±30° 是交互映射，不是特定透镜的真实折射模型。

视觉跟踪采用低分辨率灰度块匹配，只估算二维平移。没有三维定位、自动平面识别、透视校正或真实 AR 遮挡。大幅移动、旋转、重复纹理、反光、亮度变化会影响跟踪。倾斜控制以手机竖屏使用为宜。

高 LPI 条纹往往超出相机可解析能力；软件无法恢复已被镜头模糊或摩尔纹破坏的信息。每帧条纹低于 1 像素时界面会提示不足。导入图最长边限制为 4096 像素，摄像头取样最长边 1800 像素，用于控制手机内存与算力；缩放可能损失细条纹。真实已覆透镜的光栅成品本身就会随角度变化，此项目面向未覆透镜的交错图软件模拟。

## 验证

`node core.test.cjs` 验证节距、帧边界、交错恢复、相位偏移及二维位移跟踪。真实手机摄像头、权限、传感器与印刷图仍需实机验证。

浏览器接口参考：[getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)、[方向权限](https://developer.mozilla.org/en-US/docs/Web/API/DeviceOrientationEvent/requestPermission_static)。
