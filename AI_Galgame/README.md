# 《恋爱模型：请与AI少女对话！~ AI Maiden Simulator ~》
### A Cyberpunk Anime Dating Simulator / Visual Novel (Galgame)
> 基于 **HTML5 + CSS3 + Vanilla JavaScript** 构建的纯前端二次元美少女文字冒险游戏（Galgame），结合互联网各大知名主流大模型（DeepSeek、ChatGPT、Claude 等）的官方特征与民间主流二创拟人形象，打造趣味、浪漫与梗度拉满的赛博恋爱冒险。

## 🎮 完整的视觉小说系统引擎 (VN Engine)

* 🔊 **纯原生 Web Audio 动态和弦合成器**：
  * **100% 离线可用**，无需加载任何外部 mp3/wav 资源。
  * 内置 **6 首不同风格的 BGM 旋律**（标题曲、校园日常曲、DeepSeek欢快8-bit萌音、ChatGPT知性电音、Claude抒情华尔兹圆舞曲、心动催泪钢琴曲）。
  * 真实音效（打字轻音、按钮悬停、好感度增加叮咚声、DeepSeek思考音、警报声、心跳声）。
* 🎨 **高精矢量 SVG 立绘系统**：
  * 支持多表情无损放大与切换（平常、思考、害羞脸红、傲娇炸毛、大笑、吃白米饭）。
  * 呼吸动效、鲸鱼大尾巴自然摇晃摆动、呆毛晃动、羽毛笔微光悬浮、眼镜反光HUD。
* 💻 **专属二创互动机制**：
  * DeepSeek 专属 `<think>` 思考链悬浮窗口，实时展示思维链推理。
  * 好感度系统：每次选择实时增加特定角色好感度（+❤️ 浮动动画），并在顶部 HUD 实时追踪。
* 📂 **完备的 Galgame 标配功能**：
  * **打字机特效**：支持点击瞬间出字。
  * **AUTO / SKIP**：自动播放与极速快进。
  * **LOG (Backlog)**：随时回溯查看全部历史对话。
  * **SAVE / LOAD**：基于 LocalStorage 的 6 槽位存档/读档，记录时间、场景与好感度。
  * **GALLERY (结局鉴赏库)**：收录 8 个分支结局，新增 Claude「虚构地域限制」中文与英文 Ban End。
  * **AI CODEX (角色档案室 & 试衣间)**：自由切换角色立绘与 6 种表情/动作，查看详细二创考据。
  * **SETTINGS (系统设置)**：独立调节 BGM 音量、音效音量、打字速度与一键静音。
* 📜 **Claude 双语特别结局**：在个人线告白时，可选择中文或英文表达「我来自中国」；两条路线均有独立剧情、系统提示与图鉴收录。地域限制仅为虚构平行世界的剧情设定，不代表真实服务政策。
* 🌐 **完整中英双语**：使用标题画面或游戏内右上角的语言按钮切换中文/English；菜单、剧情、选项、角色档案、结局图鉴及提示都会同步切换，且会记住上次选择。

## 🚀 启动与体验方式

由于本游戏完全由纯正的原生 Web 前端（HTML5 + CSS3 + ES6 JavaScript）编写，无需任何安装步骤：

1. **直接启动**：
   在资源管理器中双击打开 `AI_Galgame/index.html`，或将其拖入任意现代浏览器（Chrome、Edge、Safari、Firefox）即可畅玩。
2. **本地静态服务预览（可选）**：
   若使用 VS Code 或 Antigravity，可直接右键 `index.html` 选择 `Open with Live Server`。
